Read, write, and share

Use the rules together in one phrase, then see how music can be written and shared.

Rule: Find the octave marker and tempo first. Read each note's height, then its start and width. Read extra marks last.

Read it step by step

  1. Find the octave dot and tempo.
  2. Read each note's height.
  3. Count starts and widths in beats.
  4. Read any extra marks.

A phrase is a short musical thought. This one rises from C to D to E, then ends with a longer note. The curved slur joins the first two smoothly.

Writing Tristaff

Tristaff can be written on paper. The challenge is precision: every semitone needs its own height, and each beat needs a consistent width. A small placement error can make a pitch or length unclear. This asks for more exact spacing than a five-line staff, where a sharp or flat can change a pitch without moving the note.

Tristaff was designed for digital editing. A program can keep those positions exact while you move or change notes. madscore is one implementation that lets you write a Tristaff score and hear it.

Music technology · If you want to go deeper

What does a music file keep?

A file may describe written notes, a performance, a finished page, or the sound itself. These are different kinds of information.

Notation dataMusicXML · .musicxml, .xml, .mxl

XML tags describe notes, bars, and symbols. Notation programs use it to exchange scores. A new program may lay out the page differently.

Notation textABC · .abc

Letters, numbers, and symbols describe a tune in plain text. A person can edit it with a text editor; a program can turn it into notation or sound.

Performance eventsMIDI · .mid

Timed messages say when notes start and stop, how strongly to play them, and which instruments to use. A player makes the sound. MIDI stores no recording or fixed page layout.

General dataJSON · .json

A text format for structured data. A music program can store notes and marks in JSON, but another program needs to know that program's rules to read them.

PagePDF · .pdf

Keeps the appearance of pages for viewing or printing. It is much harder to edit as notes than a notation file.

Audio samplesWAV · .wav

Usually holds uncompressed measurements of the sound wave. It preserves the recorded sound closely but can make a large file.

Compressed audioMP3 · .mp3

Stores recorded sound in less space. Its lossy compression discards some sound detail to make the file smaller.

ContainerOgg · .ogg

Holds an encoded media stream. Ogg Vorbis or Ogg Opus commonly holds compressed sound; Ogg itself is the wrapper, not one sound encoding.

Sound files such as WAV, MP3, and Ogg let you hear a performance, but they do not tell you exactly which notes were written. MIDI keeps note events but needs a sound maker. Notation formats keep written music, but may not keep the same page design in every program.
